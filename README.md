# Marble Lab · 弹珠工坊

A tiny Three.js playground. Place ramps, bumpers and springs, release a marble, and guide it into its green home.

一个关于「想法 → 代码 → 三维交互 → 反馈 → 修改」的可运行实验。

## Play

Select a piece, then click a mounting point. Click an existing piece to select it. Rotate ramps and bumpers in 15° steps, then release the marble. Use **试试一个搭法** for a verified example, then change it and experiment.

- **Space**: release a marble
- **R**: rotate the selected piece
- **Delete / Backspace**: remove the selected piece
- **重试**: stop the simulation and keep the layout
- **清空桌面**: remove the layout

Keyboard-accessible mounting buttons are available under the board. Sound is opt-in. The game needs a WebGL-capable browser. No API key or account is needed to run it locally.

## Run locally

Node.js 22.13+ and npm:

```sh
npm ci
npm run dev
```

Open the URL printed by the development server.

```sh
npm test
npm run typecheck
npm run build
```

## What is implemented

- Three.js geometry, lighting, shadows, marble trail and success particles.
- A 4 × 4 mounting grid with ramps, elastic bumpers and spring bumpers.
- Fixed-step planar physics at 120 Hz, separate from rendering.
- Immutable layout between attempts; deterministic retries for the same layout.
- Goal crossing, falling out, timeout, stop/retry and full reset.
- Mouse, touch and keyboard controls, responsive layout and optional synthesized audio.

The scene is rendered in 3D; motion is deliberately constrained to a plane. This is an arcade prototype, not a general-purpose rigid-body engine. Layouts are session-local and reset when the page reloads. Model generation is part of the development process, not a service called during gameplay.

## Project map

- `app/page.tsx`: interaction, editing/running/result states and browser lifecycle.
- `lib/game/physics.ts`: pure simulation, authoritative ball state and goal rules.
- `lib/game/scene.ts`: Three.js rendering and board picking.
- `tests/physics.test.ts`: tests against the same physics used by the app.
- `docs/architecture.md`: state and context decisions.
- `experiments/001-mvp/result.md`: implementation and validation record.

Built with the Sites React/Vinext starter and Three.js. Source is independently implemented; this is not the original Tidal Rush code or an exact reproduction of its generation process.
