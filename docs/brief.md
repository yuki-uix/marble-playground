# MVP brief

Create a real Three.js toy that users can interact with. A desktop marble workshop: place a ramp, bumper or spring in mounting slots, rotate the selected piece, release a ball, then adjust and try again. Keep playfulness through color, motion, a visible trail and success feedback. Publish source on GitHub and retain a concise development record.

Out of scope: accounts, backend, LLM calls during gameplay, user uploads, multiplayer, full 3D rigid-body simulation, free dragging and saved user levels.

Visual direction: a blue miniature workshop board, yellow marble/ramps, sky-blue bumpers, pink springs and a mint-green goal. The play surface is the main content, with a compact toolbox beside it.
